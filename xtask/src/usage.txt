xtask — repository automation for ocpi-kit

  sync-fixtures            Copy every JSON example from specs/src/ into fixtures/, and extract
                           the inline examples that OCPI 2.1.1 embeds in Markdown.

  spec-coverage [--check]  Parse the property tables out of the vendored specification and
                           compare them with the fields this crate defines. Reports every field
                           the spec has and the crate does not, and vice versa.
                           With --check, exits non-zero when anything is missing, which is what
                           CI runs.

  enum-coverage [--check]  Parse the enum value tables out of the vendored specification and
                           compare them with the values this crate declares. A missing value on
                           a closed enum makes a conformant peer's object undecodable; on an open
                           enum it survives as `Custom(_)` and silently never matches a `match`.
                           With --check, exits non-zero when anything is missing. CI runs it.

  field-shapes [--check]   Compare every field's cardinality (`1`, `?`, `*`, `+`) and declared
                           length with the same property tables. A field the spec marks optional
                           and the crate makes required rejects a conformant peer; a length that
                           is too small reports a conformant value as TooLong and refuses to send
                           it. With --check, exits non-zero on a mismatch. CI runs it.

  dead-config              Check that every public configuration field is read somewhere, not
                           merely assigned. A setting that does nothing is worse than a missing
                           feature: somebody sets it, believes the problem is handled, and ships.
                           CI runs it.

  no-floats                Scan the wire models and the pricing engine for `f32`/`f64`. Money in
                           OCPI is an exact decimal; a float in an object field or a cost
                           computation is a defect. CI runs it.
