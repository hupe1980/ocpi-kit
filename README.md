# ocpi-kit

A Rust toolkit for the [OCPI](https://evroaming.org/ocpi/) (Open Charge Point Interface)
protocol used for EV roaming between Charge Point Operators (CPO), e-Mobility Service
Providers (eMSP) and roaming hubs.

> **Status: placeholder.** Version 0.0.1 reserves the crate name and contains no
> functionality yet. Work in progress — watch this repository for the first usable release.
